# Bust geometry pilot (superseded)

The one-scene Bust pilot succeeded in Unity 5.6.7f1 and visually restored the
map. Its repair method has now been generalized to every scene, including Menu.

Use the current universal instructions in:
[map-geometry-repair.md](map-geometry-repair.md).

The universal installer automatically backs up and removes the obsolete pilot
`BustGeometry.json` from a project. The Unity menu keeps **Repair Bust geometry**
only as a no-change/pilot check, and **Revert Bust pilot repair** remains
available for the separate pilot receipt.
