# Extracted shader texts

Ground-truth ShaderLab texts decompiled from the original Block Strike 608 APK
(Unity 4.7.2 serialized Shader assets). Generated by `tools/extract_apk_shader_texts.py`.

These are lossless at the render-semantics level: original shader names,
Properties blocks and pass render state are byte-faithful. Programmable passes
are stored as their compiled GLES/GLES3 programs, which are translated back to
equivalent CG in the ShaderRecovery replacements.
